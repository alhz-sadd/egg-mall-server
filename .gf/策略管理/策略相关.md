1。管理端-获取用户当前策略 接口名称名称 [/api/admin/](http://localhost:7001/swagger-ui.html#/%E7%AE%A1%E7%90%86%E7%AB%AF-%E7%AD%96%E7%95%A5%E7%AE%A1%E7%90%86/controller-admin\strategy-index)getUserPolicy

接口描述：获取某个用户的绑定策略，每个用户注册时候默认绑定，[/api/admin/strategies](http://localhost:7001/swagger-ui.html#/%E7%AE%A1%E7%90%86%E7%AB%AF-%E7%AD%96%E7%95%A5%E7%AE%A1%E7%90%86/controller-admin\strategy-index)获取策略列表下 type=0 （0=默认）的策略，这个接口主要就获取绑定的策略数据

数据结构：{}

1.1。管理端-绑定用户策略：接口名称名称 `POST /api/admin/bindUserPolicy`
接口描述：管理端给用户绑定策略，传入 `userId` 和 `strategyId`。绑定后，会将用户的任务状态重置为未开启。

1.2。管理端-开启用户任务：接口名称名称 `POST /api/admin/startUserTask`
接口描述：管理端开启用户任务，传入 `userId`。要求用户当前绑定的策略为非默认策略（`type != 0`），否则提示报错，开启后用户方可接收任务。

1.3。管理端-获取用户任务状态：接口名称名称 `GET /api/admin/getUserTaskStatus`
接口描述：管理端查询指定用户任务是否已开启，传入 `userId`，返回 `is_task_started` 布尔值。

2。移动端-获取用户任务信息: 接口名称名称 `/api/mobile/getUserTaskInfo`
接口描述：h5 用户 获取用户任务统计信息,
数据结构：

```json
{
"freeze_money": 0.00,（用户冻结的任务收益）
"has_money": 0.00,（用户可用余额）
"num": 60,（用户可进行的任务数量,根据用户的"user_vip"等级（这个值1=30 2=60 3=90），num挂钩用户的"user_vip"等级，用户等级越高，num越多）
"over_num": 0,（用户已完成的任务数量）
"revenue_today": 0.00,（用户今日任务收益）
"revenue_yesterday": 0.00,（用户昨日任务收益）
}
```

3.移动端-搜索任务接口名称名称  `/api/mobile/searchTask`
接口描述：h5 用户 搜索任务
数据结构：

```json
{
    "code": 200 || 500,
    "msg": "操作成功",（根据code判断是否成功，200=成功，500=失败）
    "data": {
        "overNum": 0,（用户已完成的任务数量）
        "task_status": 2, （任务状态 0=订单未支付， 1用户金额低于20， 2=用户已开启任务， 3=用户已完成任务，4任务订单未支付）
      
        "wares": {
          "id": 123456789,（商品id | 唯一 |）
          "name": ",（商品名称）           "picUrl": ",（商品图片）
          "price": "763.99",（商品价格）
          "backRate": "0.006",（商品返回率）
          "backRateView": "0.6%",（商品返回率显示）
          "backMoney": "4.58394",（商品返回金额）
          "staticBackMoney": "4.58394",（商品静态返回金额）
          "trendBackMoney": "4.58394",（商品趋势返回金额）
          "ruleType": 0,（商品规则类型 0=普通商品，1=幸运商品）
          "timeLimit": null,（商品时间限制 | 默认null | 暂不开启）
        },
      
        "order": {
          "orderId": 123456789,（订单号 | 唯一 | 9位数字）
          "price": "763.99",（订单金额）
          "backRate": "0.006",（订单返回率）
          "backRateView": "0.6%",（订单返回率显示）
          "backMoney": "4.58394",（订单返回金额 | 等于 订单金额 * 订单返回率）
          "staticBackMoney": "4.58394",（订单静态返回金额）
          "trendBackMoney": "4.58394",（订单趋势返回金额）
          "ruleType": 0,（订单规则类型 0=普通订单，1=幸运订单）
          "timeLimit": null,（订单时间限制 | 默认null | 暂不开启）
        },
        "isLucky": false,（是否为幸运订单 | true是 | false 否）
    },
    "status": true
}
```

task_status 0=任务未开启， 1用户金额低于20， 2=用户已开启任务， 3=用户已完成任务，4任务订单未支付
wares 任务商品库里随机取一个商品信息，抽取过得商品不能再抽取，避免重复，商品信息包含全部商品内容
order 订单信息包含：订单号，orderId，策略id，，cTime（创建时间），uTime（更新时间）
