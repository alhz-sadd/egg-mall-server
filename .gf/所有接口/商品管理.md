# 商品中心模块

## 1. 核心业务声明与注意事项

> 1. **A端 (admin-inner)**：平台总后台管理所有商品。由于是新架构，所有操作必须对应 `shop_goods` 表。
> 2. **C端 (mobile)**：移动端获取已上架（status=1）的商品列表。C 端为唯一公开商品接口，替代了原有的普通商品列表和任务商品列表接口。支持分类、商品类型过滤以及价格排序。
>
> **涉及的数据表**:
>
> - `goods`: 全新的商品表
> - `goods_category`: 商品分类表

## A端 (Admin-Inner) 平台商品管理

### 获取商品列表

- **路径**: `GET /api/admin-inner/goods`
- **描述**: A端获取商品列表（支持普通商品和任务商品）。
- **请求头 (Headers)**:
  - `Authorization`: `Bearer <token>`
- **请求参数 (Query)**:

| 字段名        | 类型 | 必填 | 描述             |
| :------------ | :--- | :--- | :--------------- |
| `goods_name`  | string | 否 | 商品名称 (支持模糊搜索) |
| `goods_no`    | string | 否 | 商品编码 |
| `goods_type`  | int | 否 | 商品类型 |
| `status`      | int | 否 | 状态 |
| `is_home`     | int | 否 | 是否首页显示 |
| `category_id` | int | 否 | 分类ID |
| `order_by`    | string | 否 | 排序方式 (price_asc/price_desc) |
| `page`      | int  | 否   | 页码，默认1      |
| `page_size` | int  | 否   | 每页数量，默认10 |

- **响应数据**:
  ```json
  {
    "code": 200,
    "message": "success",
    "data": {
      "list": [],
      "pagination": {
        "total": 0,
        "page": 1,
        "page_size": 10
      }
    }
  }
  ```

### 获取商品详情

- **路径**: `GET /api/admin-inner/goods/:id`
- **描述**: A端获取指定商品的详细信息。
- **请求头 (Headers)**:
  - `Authorization`: `Bearer <token>`
- **请求参数 (Path)**:
  - `id` (int): 商品ID
- **响应数据**:
  ```json
  {
    "code": 200,
    "message": "success",
    "data": {
      "goods_id": 1,
      "goods_name": "商品名称",
      "goods_no": "G123456",
      "category_id": 1,
      "price": "99.99"
    }
  }
  ```

### 新增商品

- **路径**: `POST /api/admin-inner/goods`
- **描述**: A端新增商品。
- **请求头 (Headers)**:
  - `Authorization`: `Bearer <token>`
- **请求参数 (Body)**:

| 字段名          | 类型   | 必填 | 描述                   |
| :-------------- | :----- | :--- | :--------------------- |
| `goods_name`  | string | 是   | 商品名称               |
| `category_id` | int    | 是   | 商品分类ID             |
| `price`       | number | 是   | 商品价格               |
| `is_home`     | int    | 否   | 是否首页显示 (1是 0否) |
| `goods_no`    | string | 否   | 商品编码 (不传自动生成)|
| `cover_image` | string | 否   | 商品主图               |
| `images`      | string | 否   | 多张图JSON数组         |
| `stock`       | int    | 否   | 库存数量 (不传或为空视为无限库存)|
| `sales`       | int    | 否   | 销量                   |
| `content`     | string | 否   | 商品详情富文本         |
| `sort`        | int    | 否   | 排序                   |
| `status`      | int    | 否   | 上架状态 (1上架 0下架) |
| `remark`      | string | 否   | 后台备注               |

- **响应数据**:
  ```json
  {
    "code": 200,
    "message": "创建成功",
    "data": {}
  }
  ```

## C端 (Mobile) 商品列表

### 获取商品列表 (公开)

- **路径**: `GET /api/mobile/public/home-products`
- **描述**: 移动端获取已上架（status=1）的商品列表。此为唯一公开商品接口，支持商品类型过滤以及价格排序。
- **请求头 (Headers)**:
  - 无需 Token
- **请求参数 (Query)**:

| 字段名         | 类型   | 必填 | 描述                                                                      |
| :------------- | :----- | :--- | :------------------------------------------------------------------------ |
| `goods_type` | int    | 否   | 商品类型 (1普通商品 2任务商品)                                            |
| `order_by`   | string | 否   | 排序方式：price_asc(价格从低到高), price_desc(价格从高到低)，默认按ID倒序 |
| `page`       | int    | 否   | 页码，默认1                                                               |
| `page_size`  | int    | 否   | 每页数量，默认10                                                          |

- **响应数据**:
  ```json
  {
    "code": 200,
    "message": "获取成功",
    "data": {
      "list": [
        {
          "goods_id": 101,
          "goods_name": "测试商品",
          "goods_type": 1,
          "cover_image": "https://...",
          "image": "https://...",
          "imageUrl": "https://...",
          "price": "99.00"
        }
      ],
      "total": 1,
      "page": 1,
      "page_size": 10
    }
  }
  ```
