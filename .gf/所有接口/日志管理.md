# 日志管理

## 操作日志

### 1. 获取操作日志列表
- **路径**: `GET /api/admin-inner/operation-logs` / `GET /api/admin-outer/operation-logs`
- **描述**: 查询操作日志列表（A端查全部，B端查本店）。
- **请求头 (Headers)**:
  - `Authorization`: `Bearer <token>`
- **请求参数 (Query)**:
  | 字段名 | 类型 | 必填 | 描述 |
  | ------ | ---- | ---- | ---- |
  | page | int | 否 | 页码，默认1 |
  | page_size | int | 否 | 每页数量，默认10 |
  | oper_username | string | 否 | 操作人员账号 |
  | oper_status | int | 否 | 操作状态（0异常 1正常） |
  | oper_module | string | 否 | 操作模块 |
  | oper_type | int | 否 | 操作类型（0新增 1修改 2删除 3授权 4导出 5导入 6强退 7生成代码 8清除数据 9其他） |
  | oper_location | string | 否 | 操作地点（支持模糊搜索） |
  | start_time | string | 否 | 开始时间 (YYYY-MM-DD HH:mm:ss) |
  | end_time | string | 否 | 结束时间 (YYYY-MM-DD HH:mm:ss) |
- **响应数据**:
  ```json
  {
    "code": 200,
    "message": "success",
    "data": {
      "total": 100,
      "list": [
        {
          "id": 1,
          "log_no": "OP123",
          "module": "员工管理",
          "oper_type": "修改",
          "oper_desc": "员工管理 - 修改",
          "oper_name": "admin",
          "oper_ip": "127.0.0.1",
          "oper_location": "本地",
          "status": "正常",
          "oper_time": "2024-01-01 12:00:00",
          "request_info": {
            "req_module": "员工管理",
            "req_url": "/api/admin-inner/employees/1",
            "req_params": { "status": 1 },
            "req_method": "PUT",
            "res_body": "code:200,msg:\"修改成功\"",
            "res_status": "正常",
            "req_desc": "员工管理"
          }
        }
      ],
      "page": 1,
      "page_size": 10
    }
  }
  ```

### 2. 批量删除操作日志
- **路径**: `DELETE /api/admin-inner/operation-logs/batch`
- **描述**: 平台端根据ID批量删除操作日志。
- **请求头 (Headers)**:
  - `Authorization`: `Bearer <token>`
- **请求参数 (Body)**:
  | 字段名 | 类型 | 必填 | 描述 |
  | ------ | ---- | ---- | ---- |
  | ids | array | 是 | 日志ID数组，如 [1, 2, 3] |
- **响应数据**:
  ```json
  {
    "code": 200,
    "message": "删除成功",
    "data": null
  }
  ```

### 3. 清空操作日志
- **路径**: `DELETE /api/admin-inner/operation-logs/clear`
- **描述**: 平台端清空所有操作日志。
- **请求头 (Headers)**:
  - `Authorization`: `Bearer <token>`
- **请求参数**: 无
- **响应数据**:
  ```json
  {
    "code": 200,
    "message": "清空成功",
    "data": null
  }
  ```

## 登录日志

### 4. 获取登录日志列表
- **路径**: `GET /api/admin-inner/login-logs`
- **描述**: 平台端查询全平台的登录日志列表。
- **请求头 (Headers)**:
  - `Authorization`: `Bearer <token>`
- **请求参数 (Query)**:
  | 字段名 | 类型 | 必填 | 描述 |
  | ------ | ---- | ---- | ---- |
  | page | int | 否 | 页码，默认1 |
  | page_size | int | 否 | 每页数量，默认10 |
  | username | string | 否 | 登录账号 |
  | login_result | int | 否 | 状态：0登录失败 1登录成功 |
  | login_ip | string | 否 | 登录IP（支持模糊搜索） |
  | login_location | string | 否 | 登录地点（支持模糊搜索） |
  | device_type | int | 否 | 设备类型：1 PC电脑 2安卓 3 iOS苹果 4其他设备 |
- **响应数据**:
  ```json
  {
    "code": 200,
    "message": "success",
    "data": {
      "total": 50,
      "list": [
        {
          "id": 1,
          "log_no": "xxx",
          "user_id": 1,
          "username": "admin",
          "login_ip": "127.0.0.1",
          "login_location": "本地",
          "device_type": 1,
          "browser": "Chrome",
          "os": "Windows11",
          "login_type": 1,
          "login_result": 1,
          "login_time": "2024-01-01 12:00:00"
        }
      ],
      "page": 1,
      "page_size": 10
    }
  }
  ```
