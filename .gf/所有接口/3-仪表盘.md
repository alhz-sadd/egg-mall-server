# 首页仪表盘

该模块提供 A端（内部平台）和 B端（商家端）首页的各项统计数据展示。
A端获取的整个平台的总数据
B端获取的店铺的总数据
C端不需要改接口

**涉及核心表：**

- `sys_user` (用户表，A端注册人数)
- `customer_relation` (C端归属表，B端注册人数及过滤)
- `user_recharge` (充值表)
- `user_withdraw` (提现表)
- `user_wallet_log` (资金流水表，用于统计佣金等)

---

## 1. A端 - 平台仪表盘数据

- **路径**: `GET /api/admin-inner/dashboard/stats`
- **描述**: 获取 A端 首页仪表盘统计数据（汇总全平台所有店铺的数据）。
- **请求头 (Headers)**:
  - `Authorization`: `Bearer <token>`
- **请求参数**: 无
- **响应数据**:
  ```json
  {
    "code": 200,
    "message": "获取成功",
    "data": {
      "today": {
        "register_count": 10,
        "recharge_amount": 5000,
        "withdraw_amount": 1000,
        "performance_amount": 6000,
        "first_recharge_count": 5,
        "repeat_recharge_count": 2,
        "commission_amount": 300
      },
      "month": {
        "register_count": 150,
        "recharge_amount": 50000,
        "withdraw_amount": 20000,
        "commission_amount": 1500
      },
      "review": {
        "recharge_pending_count": 2,
        "withdraw_pending_count": 1
      }
    }
  }
  ```

---

## 2. B端 - 店铺仪表盘数据

- **路径**: `GET /api/admin-outer/dashboard/stats`
- **描述**: 获取 B端 首页仪表盘统计数据（仅展示当前登录账号归属店铺 `shop_id` 的数据）。
- **请求头 (Headers)**:

  - `Authorization`: `Bearer <token>`
- **请求参数**: 无
- **响应数据**: 同上 A端数据结构，仅数据范围被限定为当前店铺。
