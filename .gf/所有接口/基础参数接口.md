# 基础参数配置 (Admin-Inner)

> **核心业务声明与注意事项**：
> 1. 本模块负责 A 端（平台管理端）全局基础参数的维护。
> 2. **全局模板**：使用 `shop_id = 0` 表示全局配置模板，作为新店铺初始化配置的基准。
> 3. **配置覆盖**：为指定店铺更新参数时，如果该店铺尚无私有配置，系统会自动基于全局模板创建一份并应用修改。
> 4. **参数命名**：所有接口参数强制使用蛇形命名法（snake_case）。

**涉及的数据表**：
- `shop_config`

## 1. 获取系统全局基础参数 (A端)

- **接口地址**: `GET /api/admin-inner/system/config`
- **请求方式**: `GET`
- **说明**: 获取全局默认配置模板 (shop_id = 0)。
- **返回数据结构**:

```json
{
  "code": 200,
  "message": "获取成功",
  "data": {
    "config_id": 1,
    "shop_id": 0,
    "real_name_reward": "0.00",
    "order_pay_timeout_switch": 0,
    "order_pay_timeout": 1800,
    "withdraw_min_amount": "20.00",
    "withdraw_max_amount": "99999.00",
    "withdraw_fee_type": 2,
    "withdraw_fee_value": "0.03",
    "recharge_fee_rate": "0.0000",
    "withdraw_first_need_task": 0,
    "withdraw_first_need_identity": 0
  }
}
```

## 2. 设置系统全局基础参数 (A端)

- **接口地址**: `PUT /api/admin-inner/system/config`
- **请求方式**: `PUT`
- **说明**: 更新全局默认配置模板 (shop_id = 0)。
- **请求参数 (Body)**: (全部为可选字段)
  | 字段名 | 类型 | 必填 | 描述 |
  | :--- | :--- | :--- | :--- |
  | real_name_reward | number | 否 | 实名奖励金额 |
  | order_pay_timeout_switch | integer | 否 | 0关闭 1开启 |
  | order_pay_timeout | integer | 否 | 超时时间，单位秒 |
  | withdraw_min_amount | number | 否 | 提现最小金额 |
  | withdraw_max_amount | number | 否 | 提现最大金额 |
  | withdraw_fee_type | integer | 否 | 1固定金额，2百分比 |
  | withdraw_fee_value | number | 否 | 提现手续费值 |
  | recharge_fee_rate | number | 否 | 充值手续费比例，如 0.03 表示 3% |
  | withdraw_first_need_task | integer | 否 | 0不需要，1需要 |
  | withdraw_first_need_identity | integer | 否 | 0不需要，1需要 |
- **返回数据结构**:

```json
{
  "code": 200,
  "message": "更新成功",
  "data": { ... }
}
```

## 3. 给指定店铺绑定更新基础参数 (A端)

- **接口地址**: `PUT /api/admin-inner/shops/:shop_id/config`
- **请求方式**: `PUT`
- **说明**: 为指定店铺更新配置。如果该店铺尚无私有配置，则会基于全局模板创建一份并应用传入的更新。
- **请求参数 (Body)**: 同“设置系统全局基础参数”。
- **返回数据结构**:

```json
{
  "code": 200,
  "message": "更新成功",
  "data": { ... }
}
```
