# 客户管理 (Admin-Inner / Admin-Outer)

该模块提供给 A 端平台（admin-inner）管理 C 端注册客户信息。

## 4. 修改客户提现密码

- **路径**: `PUT /api/admin-inner/customers/:id/withdraw-password`
- **描述**: 修改指定客户的提现密码。
- **请求头 (Headers)**:
  - `Authorization`: `Bearer <token>`
- **路径参数 (Params)**:
  - `id` (Long, 必填): 客户主键ID
- **请求参数 (Body)**:| 字段名       | 类型   | 必填 | 描述       |
  | ------------ | ------ | ---- | ---------- |
  | withdraw_pwd | String | 是   | 新提现密码 |

## 5. 获取店铺下的C端用户列表 (仅B端)

- **路径**: `GET /api/admin-outer/customers`
- **描述**: B端特有接口，获取当前店铺下的C端用户列表。店长可以看到店铺下所有C端用户，业务员只能看到自己直推及衍生的C端用户。
- **请求头 (Headers)**:
  - `Authorization`: `Bearer <token>`
- **请求参数 (Query)**:| 字段名       | 类型   | 必填 | 描述                                    |
  | ------------ | ------ | ---- | --------------------------------------- |
  | page         | int    | 否   | 页码，默认1                             |
  | page_size    | int    | 否   | 每页数量，默认10                        |
  | keyword      | string | 否   | 模糊搜索（用户名/手机号/昵称）          |
  | username     | string | 否   | 用户名（精确匹配）                      |
  | phone        | string | 否   | 手机号（精确匹配）                      |
  | user_id      | int    | 否   | 客户ID                                  |
  | parent_id    | int    | 否   | 上级客户ID                              |
  | salesman_id  | int    | 否   | 归属业务员ID                            |
  | user_level   | int    | 否   | 客户层级                                |
  | user_ip      | string | 否   | 登录IP                                  |
  | has_recharge | int    | 否   | 是否充值过 (1是 0否)                    |
  | is_virtual   | int    | 否   | 是否虚拟用户 (1是 0否)                  |
  | is_real_user | int    | 否   | 是否真实用户 (1是 0否)                  |
  | status       | int    | 否   | 状态 (1正常 0禁用)                      |
  | start_time   | string | 否   | 注册时间区间(开始)                      |
  | end_time     | string | 否   | 注册时间区间(结束)                      |
  | sort         | string | 否   | 排序方式 (如 balance_asc, balance_desc) |

## 1.5 获取C端用户资金明细

- **路径**:
  - A端: `GET /api/admin-inner/customers/:id/fund-details`
  - B端: `GET /api/admin-outer/customers/:id/fund-details`
- **描述**: 获取指定用户的资金变动流水，包含充值、提现、收益、系统加扣款等明细。
- **请求头 (Headers)**:
  - `Authorization`: `Bearer <token>`
- **路径参数 (Params)**:
  - `id` (Long, 必填): 客户主键ID
- **请求参数 (Query)**:| 字段名    | 类型 | 必填 | 描述                                                           |
  | --------- | ---- | ---- | -------------------------------------------------------------- |
  | page      | int  | 否   | 页码，默认1                                                    |
  | page_size | int  | 否   | 每页数量，默认10                                               |
  | type      | int  | 否   | 变动类型 (0任务收益 1充值 2团队收益 3系统增加 4系统减少 5提现) |

## 1.6 后台资金充值与扣除

- **路径**: `POST /api/admin-outer/customers/:id/balance`
- **描述**: B端后台人工对客户进行资金的充值或扣除。
- **请求头 (Headers)**:
  - `Authorization`: `Bearer <token>`
- **路径参数 (Params)**:
  - `id` (Long, 必填): 客户主键ID
- **请求体参数 (Body JSON)**:| 字段名      | 类型   | 必填 | 描述                  |
  | ----------- | ------ | ---- | --------------------- |
  | amount      | number | 是   | 变动金额 (必须大于0)  |
  | change_type | int    | 是   | 操作类型: 1充值 2扣除 |
  | remark      | string | 否   | 备注                  |
- **响应数据示例**:
  ```json
  {
    "code": 200,
    "message": "充值成功"
  }
  ```

## 4. 客户人工资金调整 (上分/下分)

> 基于 `user_wallet` 架构，仅影响用户的代金资产 (`voucher_balance`)。同时产生 `biz_type` 为 8 或 9 的流水。

### A端 / B端 获取人工加款(上分)记录列表

- **路径**:
  - A端: `GET /api/admin-inner/points-give/list`
  - B端: `GET /api/admin-outer/points-give/list`
- **描述**: 获取后台人工上分记录。B端只能查看本店C端客户的记录。
- **请求头 (Headers)**:
  - `Authorization`: `Bearer <token>`
- **请求参数 (Query)**:| 字段名     | 类型   | 必填 | 描述                |
  | ---------- | ------ | ---- | ------------------- |
  | page       | int    | 否   | 页码，默认1         |
  | page_size  | int    | 否   | 每页数量，默认10    |
  | username   | string | 否   | C端用户名(模糊搜索) |
  | user_id    | int    | 否   | 目标用户ID          |
  | start_time | string | 否   | 变动时间区间(开始)  |
  | end_time   | string | 否   | 变动时间区间(结束)  |
- **响应数据示例**:
  ```json
  {
    "code": 200,
    "message": "获取成功",
    "data": {
      "total": 1,
      "list": [
        {
          "id": 1,
          "operator_id": 2,
          "operator_name": "业务员李四",
          "user_id": 10086,
  ```

### B端 人工加款(上分)

- **路径**:
  - B端: `POST /api/admin-outer/points-give/create`
