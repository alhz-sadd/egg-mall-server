# 参数配置接口文档

本文档包含了所有端（A端/B端）对店铺参数配置（`shop_config` 表）的获取与修改接口。

## 1. A端 (admin-inner) - 获取店铺业务配置

- **接口地址**: `GET /api/admin-inner/shops/:shop_id/setting`
- **请求方式**: `GET`
- **说明**: A端平台管理员通过指定 `shop_id` 获取该店铺的业务配置信息。
- **返回数据结构**:

```json
{
  "code": 200,
  "message": "获取成功",
  "data": {
    "config_id": 1,
    "shop_id": 1,
    "real_name_reward": "5.00",
    "order_pay_timeout_switch": 1,
    "order_pay_timeout": 1800,
    "withdraw_min_amount": "100.00",
    "withdraw_max_amount": "99999.00",
    "withdraw_fee_type": 2,
    "withdraw_fee_value": "5.00",
    "withdraw_first_need_task": 0,
    "withdraw_first_need_identity": 1,
    "recharge_fee_rate": "0.0000",
    "create_time": "2026-09-05T12:00:00.000Z",
    "update_time": "2026-09-05T12:00:00.000Z"
  }
}
```

## 2. A端 (admin-inner) - 修改店铺业务配置

- **接口地址**: `PUT /api/admin-inner/shops/:shop_id/setting`
- **请求方式**: `PUT`
- **说明**: A端平台管理员修改指定店铺的业务配置。
- **请求参数 (Body)**: (全部为可选字段，传入即修改)
  - `real_name_reward`: number (实名奖励金额)
  - `order_pay_timeout_switch`: integer (0关闭 1开启)
  - `order_pay_timeout`: integer (超时时间，单位秒)
  - `withdraw_min_amount`: number (提现最小金额)
  - `withdraw_max_amount`: number (提现最大金额)
  - `withdraw_fee_type`: integer (1固定金额，2百分比)
  - `withdraw_fee_value`: number (提现手续费)
  - `withdraw_first_need_task`: integer (0不需要，1需要)
  - `withdraw_first_need_identity`: integer (0不需要，1需要)
  - `recharge_fee_rate`: number (充值手续费率)
- **返回数据结构**:

```json
{
  "code": 200,
  "message": "更新成功",
  "data": {
    ... // 更新后的配置数据
  }
}
```

---

## 3. B端 (admin-outer) - 获取自己店铺参数配置

- **接口地址**: `GET /api/admin-outer/shop/settings`
- **请求方式**: `GET`
- **说明**: B端店家（或有权限的业务员）获取自己所属店铺的参数配置信息。不需要传 `shop_id`，后端自动根据登录 token 解析所属店铺。
- **返回数据结构**: 与 A端获取接口相同。

## 4. B端 (admin-outer) - 修改自己店铺参数配置

- **接口地址**: `PUT /api/admin-outer/shop/settings`
- **请求方式**: `PUT`
- **说明**: B端店家修改自己所属店铺的参数配置信息。不需要传 `shop_id`，后端自动根据登录 token 识别并更新对应店铺配置。
- **请求参数 (Body)**: 与 A端修改接口的入参完全相同。
- **返回数据结构**: 同上。
