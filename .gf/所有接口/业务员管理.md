# 店铺员工管理 (Admin-Outer)

该模块提供给 B 端店家（admin-outer）管理自身店铺内的员工（包括店长和业务员）信息。

## 1. 获取员工列表

- **路径**: `GET /api/admin-outer/employees`
- **描述**: 获取当前登录店铺下的所有员工列表。支持按用户账号、手机号、状态及时间跨度进行查询。
- **请求头 (Headers)**:
  - `Authorization`: `Bearer <token>`
- **请求参数 (Query)**:| 字段名     | 类型   | 必填 | 描述                                            |
  | ---------- | ------ | ---- | ----------------------------------------------- |
  | page       | int    | 否   | 页码，默认1                                     |
  | page_size  | int    | 否   | 每页数量，默认10                                |
  | keyword    | string | 否   | 综合关键字搜索(账号/昵称)                       |
  | username   | string | 否   | 员工账号(模糊查询)                              |
  | phone      | string | 否   | 手机号(模糊查询)                                |
  | status     | int    | 否   | 状态 (1:启用, 0:禁用)                           |
  | start_time | string | 否   | 开始时间 (如:`2026-01-01 00:00:00`)           |
  | end_time   | string | 否   | 结束时间 (如:`2026-12-31 23:59:59`)           |
  | user_type  | int    | 否   | 员工类型 (2:店长, 3:业务员)，不传则默认查询两者 |
- **响应数据示例**:
  ```json
  {
    "code": 200,
    "message": "获取成功",
    "data": {
      "list": [
        {
          "user_id": 10,
          "username": "sales1",
          "user_type": 3,
          "shop_id": 1,
          "status": 1
        }
      ],
      "total": 1
    }
  }
  ```

## 2. 获取员工详情

- **路径**: `GET /api/admin-outer/employees/:id`
- **描述**: 获取指定 `user_id` 的员工详情信息。
- **请求头 (Headers)**:
  - `Authorization`: `Bearer <token>`
- **响应数据示例**:
  ```json
  {
    "code": 200,
    "message": "获取成功",
    "data": {
      "user_id": 10,
      "username": "sales1",
      "user_type": 3,
      "shop_id": 1
    }
  }
  ```

## 3. 创建员工

- **路径**: `POST /api/admin-outer/employees`
- **描述**: 在当前店铺下创建一个新员工（店长或业务员）。
- **请求头 (Headers)**:
  - `Authorization`: `Bearer <token>`
- **请求参数 (Body)**:
  | 字段名    | 类型   | 必填 | 描述                         |
  | --------- | ------ | ---- | ---------------------------- |
  | username  | string | 是   | 账号                         |
  | password  | string | 是   | 密码                         |
  | user_type | int    | 是   | 员工类型 (2:店长, 3:业务员)  |
  | nickname  | string | 否   | 昵称                         |
  | phone     | string | 否   | 手机号                       |
  | email     | string | 否   | 邮箱                         |
  | avatar    | string | 否   | 头像URL                      |
  | recharge_address | string | 否 | 业务员的收款地址 (仅user_type=3时生效) |
  | remark    | string | 否   | 备注                         |
  | status    | int    | 否   | 状态 (1:启用, 0:禁用)，默认1 |

## 4. 更新员工

- **路径**: `PUT /api/admin-outer/employees/:id`
- **描述**: 更新指定 `user_id` 的员工信息。
- **请求头 (Headers)**:
  - `Authorization`: `Bearer <token>`
- **请求参数 (Body)**:
  | 字段名    | 类型   | 必填 | 描述                  |
  | --------- | ------ | ---- | --------------------- |
  | password  | string | 否   | 新密码 (不传则不修改) |
  | nickname  | string | 否   | 昵称                  |
  | phone     | string | 否   | 手机号                |
  | email     | string | 否   | 邮箱                  |
  | avatar    | string | 否   | 头像URL               |
  | recharge_address | string | 否 | 业务员的收款地址 |
  | remark    | string | 否   | 备注                  |
  | status    | int    | 否   | 状态 (1:启用, 0:禁用) |

## 5. 删除员工

- **路径**: `DELETE /api/admin-outer/employees/:id`
- **描述**: 删除指定 `user_id` 的员工（通常为逻辑删除）。
- **请求头 (Headers)**:
  - `Authorization`: `Bearer <token>`

## 6. 重置员工登录密码

- **路径**: `POST /api/admin-outer/employees/:id/reset-password`
- **描述**: 为指定 `user_id` 的员工重置登录密码。
- **请求头 (Headers)**:
  - `Authorization`: `Bearer <token>`
- **请求参数 (Body)**:
  | 字段名       | 类型   | 必填 | 描述   |
  | ------------ | ------ | ---- | ------ |
  | new_password | string | 是   | 新密码 |
- **响应数据示例**:
  ```json
  {
    "code": 200,
    "message": "密码重置成功",
    "data": null
  }
  ```

## 7. 重置员工谷歌验证码

- **路径**: `POST /api/admin-outer/employees/:id/reset-google-auth`
- **描述**: 为指定 `user_id` 的员工重置(解绑)谷歌验证码，以便员工能正常登录并重新绑定。
- **请求头 (Headers)**:
  - `Authorization`: `Bearer <token>`
- **响应数据示例**:
  ```json
  {
    "code": 200,
    "message": "该员工的谷歌验证已重置(解绑)，可直接登录",
    "data": null
  }
  ```

## 8. 获取可用角色列表

- **路径**: `GET /api/admin-outer/roles`
- **描述**: 获取当前店铺可分配的角色类别列表（如店长、业务员），用于创建/更新员工时选择角色。
> **注意**: 根据《数据库架构总览》规定，角色由平台 (`admin-inner`) 统一管理，店铺 (`admin-outer`) **禁止创建、修改或删除**角色，仅拥有读取与分配权限。
- **请求头 (Headers)**:
  - `Authorization`: `Bearer <token>`
- **响应数据示例**:
  ```json
  {
    "code": 200,
    "message": "获取成功",
    "data": [
      {
        "role_id": 2,
        "role_name": "店长",
        "role_code": "shop_owner",
        "remark": "店铺拥有者"
      },
      {
        "role_id": 3,
        "role_name": "业务员",
        "role_code": "shop_salesman",
        "remark": "店铺业务员"
      }
    ]
  }
  ```
