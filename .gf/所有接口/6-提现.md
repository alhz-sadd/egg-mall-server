# 提现管理模块

A端不参加
B端接收C端发起的请求做成提现列表，可以通过审核，审核失败
C端1需要先获取店铺配置，发起提现请求

> **⚠️ 核心业务声明与注意事项**：
>
> 1. **A端不参与**：提现审核业务完全下放到 B 端，平台总后台不提供提现订单列表和审核接口。
> 2. **数据隔离机制**：
>    - 店长 (`isShopOwner === true`)：可以查看并审核该店铺下的所有提现订单。
>    - 业务员：只能查看并审核归属于自己的提现订单（即 `sales_user_id` 等于当前业务员 ID）。
> 3. **资金安全与原子性**：
>    - C端申请提现时：使用**悲观锁和事务**扣除可用余额(`voucher_balance`)，并将其加入冻结余额(`freeze_voucher_balance`)，同时写入流水记录。
>    - B端审核通过时：扣除冻结余额，累加累计提现金额，写流水记录。
>    - B端审核驳回时：解冻金额（将冻结余额退回到可用余额），写流水记录。
> 4. **手续费逻辑**：C端提现时需自动读取该用户所在店铺的配置表(`shop_setting`)，根据设置的比例或固定金额自动计算出 `fee` 和 `actual_receive_amount`。

> **涉及的数据表**
>
> - `user_withdraw`: 提现订单主表
> - `user_wallet`: 用户钱包表
> - `user_wallet_log`: 钱包流水表
> - `shop_setting`: 店铺配置表 (读取提现手续费)
> - `sys_user`: 账号表 (关联查询信息)
> - `customer_relation`: 客户归属关系表

## B端 (Admin-Outer) 商家/业务员操作

### 1. 获取提现统计 (昨日与今日)

- **路径**: `GET /api/admin-outer/withdraw/stats`
- **描述**: 统计昨日和今日的提现数据。店长看全店数据，业务员只看自己名下客户的数据。
- **请求头 (Headers)**:
  - `Authorization`: `Bearer <token>`
- **请求参数**: 无
- **响应数据**:
  ```json
  {
    "code": 200,
    "message": "获取成功",
    "data": {
      "today": {
        "pending_amount": "500.00",
        "success_amount": "1500.00",
        "total_users": 5
      },
      "yesterday": {
        "pending_amount": "0.00",
        "success_amount": "2000.00",
        "total_users": 8
      }
    }
  }
  ```

### 2. 获取提现订单列表

- **路径**: `GET /api/admin-outer/withdraw/list`
- **描述**: 获取提现订单分页列表。包含各种关联信息、手续费和到账金额等。
- **请求头 (Headers)**:
  - `Authorization`: `Bearer <token>`
- **请求参数 (Query)**:| 字段名    | 类型   | 必填 | 描述                                             |
  | --------- | ------ | ---- | ------------------------------------------------ |
  | page      | int    | 否   | 页码                                             |
  | page_size | int    | 否   | 每页条数                                         |
  | status    | int    | 否   | 订单状态：1待审核，2审核通过，3审核驳回，4已取消 |
  | order_no  | string | 否   | 提现订单号                                       |
- **响应数据**:
  ```json
  {
    "code": 200,
    "message": "获取成功",
    "data": {
      "list": [
        {
          "id": 1,
          "order_no": "WD12345678",
          "amount": "100.00",
          "fee": "2.00",
          "actual_receive_amount": "98.00",
          "channel_name": "usdt_trc20",
          "withdraw_address": "Txxxxxx",
          "status": 1,
          "audit_type": null,
          "user": {
            "user_id": 100,
            "username": "user1",
            "nickname": "用户1"
          },
          "sales_user": {
            "user_id": 10,
            "username": "sales1",
            "nickname": "业务员1"
          },
          "create_time": "2023-10-01T12:00:00.000Z"
        }
      ],
      "pagination": { "total": 1, "page": 1, "page_size": 10 }
    }
  }
  ```

### 3. 修改提现地址

- **路径**: `PUT /api/admin-outer/withdraw/:id/address`
- **描述**: 修改待审核状态的提现订单的提现地址。
- **请求头 (Headers)**:
  - `Authorization`: `Bearer <token>`
- **请求参数 (Body)**:| 字段名           | 类型   | 必填 | 描述     |
  | ---------------- | ------ | ---- | -------- |
  | withdraw_address | string | 是   | 新的地址 |

### 4. 审核通过

- **路径**: `POST /api/admin-outer/withdraw/:id/audit-success`
- **描述**: 审核通过提现订单，自动扣除冻结资产。
- **请求参数 (Body)**:| 字段名     | 类型 | 必填 | 描述                           |
  | ---------- | ---- | ---- | ------------------------------ |
  | audit_type | int  | 是   | 审核类型：1真实提现，2虚拟提现 |

### 5. 审核驳回

- **路径**: `POST /api/admin-outer/withdraw/:id/audit-fail`
- **描述**: 审核驳回，自动将冻结金额退回给用户。
- **请求参数 (Body)**:| 字段名        | 类型   | 必填 | 描述     |
  | ------------- | ------ | ---- | -------- |
  | reject_reason | string | 是   | 驳回原因 |

## C端 (Mobile) 用户操作

### 发起提现申请

- **路径**: `POST /api/mobile/withdraw/submit`
- **描述**: C端用户提交提现申请，验证提现密码，扣减钱包可用余额并计入冻结金额。
- **请求参数 (Body)**:| 字段名           | 类型   | 必填 | 描述         |
  | ---------------- | ------ | ---- | ------------ |
  | channel_code     | string | 是   | 提现渠道编码 |
  | withdraw_address | string | 是   | 提现钱包地址 |
  | amount           | string | 是   | 申请提现金额 |
  | withdraw_pwd     | string | 是   | 提现密码     |

### 获取提现记录列表

- **路径**: `GET /api/mobile/withdraw/list`
- **描述**: C端用户获取自己的历史提现记录。
- **请求参数 (Query)**:| 字段名    | 类型 | 必填 | 描述             |
  | --------- | ---- | ---- | ---------------- |
  | page      | int  | 否   | 页码，默认1      |
  | page_size | int  | 否   | 每页数量，默认10 |
  | status    | int  | 否   | 状态：0=全部，1=提现中，2=提现成功，3=提现失败 |

### 获取提现配置

- **路径**: `GET /api/mobile/withdraw/config`
- **描述**: C端提现页面获取手续费配置、当前可用提现渠道以及是否已设置提现密码。
- **请求参数 (Query)**: 无
- **响应数据**:
  ```json
  {
    "code": 200,
    "message": "获取成功",
    "data": {
      "has_withdraw_pwd": true,
      "withdraw_fee_type": 1,
      "withdraw_fee_value": 0.03,
      "withdraw_min_amount": 100,
      "withdraw_max_amount": 99999,
      "withdraw_first_need_task": 0,
      "withdraw_first_need_identity": 0,
      "channels": [
        {
          "channel_code": "usdt_trc20",
          "channel_name": "USDT-TRC20"
        }
      ]
    }
  }
  ```
