# 订单管理

## [B端订单列表]

- **路径**: `GET /api/admin-outer/orders`
- **描述**: 获取 B 端店铺/业务员的订单列表（即用户的任务订单进度）。店长可以获取店铺下全部订单列表，业务员获取归属自己用户的订单列表。
- **请求头 (Headers)**:
  - `Authorization`: `Bearer <token>`
- **请求参数 (Query)**:
  | 字段名       | 类型    | 必填 | 描述                                       |
  | ------------ | ------- | ---- | ------------------------------------------ |
  | page         | integer | 否   | 页码，默认 1                               |
  | page_size    | integer | 否   | 每页数量，默认 10                          |
  | user_id      | integer | 否   | 指定用户的 ID (必须属于该店长/业务员名下)  |
  | order_id     | string  | 否   | 订单号 (模糊查询)                          |
  | status       | integer | 否   | 任务子项状态 (0=未完成, 1=已完成)          |
  | is_triggered | integer | 否   | 订单是否已触发 (0=否, 1=是)                |
  | start_time   | string  | 否   | 订单创建开始时间 (格式 YYYY-MM-DD HH:mm:ss)|
  | end_time     | string  | 否   | 订单创建结束时间 (格式 YYYY-MM-DD HH:mm:ss)|
