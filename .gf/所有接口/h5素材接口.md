# H5 素材接口

本模块包含 C 端首页及相关功能页面的界面配置接口，包括轮播图 (Banner)、公告、规则管理、服务入口及在线客服。

**核心业务声明与注意事项**：
1. **统一存储**：Banner、公告、规则及服务入口统一存储在 `sys_h5_config` 表中，通过 `config_type` 区分。
2. **客服存储**：在线客服配置独立存储在 `sys_h5_service` 表中。
3. **权限隔离**：本模块接口仅限 A 端 (Admin-Inner) 平台管理员进行维护，C 端 (Mobile) 仅提供只读接口。
4. **排序规则**：所有列表接口均支持 `sort` 字段，数值越小越靠前。

**涉及的数据表**：
- `sys_h5_config`: H5 界面配置主表 (Banner/公告/规则/服务入口)
- `sys_h5_service`: H5 在线客服配置表

---

## 1. A端 (Admin-Inner) - 界面配置管理

### 轮播图管理 (Banner)

- **接口地址**:
  - `GET /api/admin-inner/h5-config/banners` (列表)
  - `POST /api/admin-inner/h5-config/banners` (新增)
  - `PUT /api/admin-inner/h5-config/banners/:id` (编辑)
  - `DELETE /api/admin-inner/h5-config/banners/:id` (删除)
- **请求参数 (Query/Body)**:
  - `title`: string (标题)
  - `image`: string (图片地址)
  - `linkUrl`: string (跳转链接，存入 extra)
  - `sort`: int (排序)
  - `status`: int (1启用 0禁用)

### 公告管理 (Notice)

- **接口地址**:
  - `GET /api/admin-inner/h5-config/notices` (列表)
  - `POST /api/admin-inner/h5-config/notices` (新增)
  - `PUT /api/admin-inner/h5-config/notices/:id` (编辑)
  - `DELETE /api/admin-inner/h5-config/notices/:id` (删除)
- **请求参数 (Query/Body)**:
  - `title`: string (标题)
  - `content`: string (公告正文)
  - `sort`: int (排序)
  - `status`: int (1启用 0禁用)

### 规则管理 (Rule)

- **接口地址**:
  - `GET /api/admin-inner/h5-config/rules` (列表)
  - `POST /api/admin-inner/h5-config/rules` (新增)
  - `PUT /api/admin-inner/h5-config/rules/:id` (编辑)
  - `DELETE /api/admin-inner/h5-config/rules/:id` (删除)

### 服务入口管理 (Service Entries)

- **接口地址**:
  - `GET /api/admin-inner/h5-config/service-entries` (列表)
  - `POST /api/admin-inner/h5-config/service-entries` (新增)
  - `PUT /api/admin-inner/h5-config/service-entries/:id` (编辑)
  - `DELETE /api/admin-inner/h5-config/service-entries/:id` (删除)

## 2. A端 (Admin-Inner) - 客服配置管理

### 客服管理

- **接口地址**:
  - `GET /api/admin-inner/h5-services` (列表)
  - `POST /api/admin-inner/h5-services` (新增)
  - `PUT /api/admin-inner/h5-services/:id` (编辑)
  - `DELETE /api/admin-inner/h5-services/:id` (删除)
- **请求参数 (Query/Body)**:
  | 字段名 | 类型 | 必填 | 描述 |
  | :--- | :--- | :--- | :--- |
  | service_name | string | 是 | 客服名称 |
  | avatar | string | 否 | 头像地址 |
  | contact_type | int | 是 | 1-微信，2-QQ，3-手机号 |
  | contact_value | string | 是 | 联系方式内容 |
  | jump_url | string | 否 | 跳转链接 |
  | sort | int | 否 | 排序 |

---

## 3. C端 (Mobile) - 界面展示接口

### 获取首页商品列表

- **路径**: `GET /api/mobile/public/home-products`
- **请求参数 (Query)**: `page`, `page_size`, `category_id`, `keyword` 等
- **描述**: 获取首页展示的商品列表。

### 获取商品详情

- **路径**: `GET /api/mobile/public/home-products/:id`
- **描述**: 获取单个商品的详细信息。

### 获取轮播图列表

- **路径**: `GET /api/mobile/public/banners`
- **描述**: 获取首页启用的轮播图列表。
- **响应数据**:
  ```json
  {
    "code": 200,
    "message": "success",
    "data": [
      {
        "id": 1,
        "title": "Banner1",
        "image": "http://url...",
        "linkUrl": "/pages/..."
      }
    ]
  }
  ```

### 获取公告列表

- **路径**: `GET /api/mobile/public/notices`
- **请求参数 (Query)**: `keyword`, `page`, `page_size`
- **描述**: 分页获取启用的公告列表。

### 获取规则图片

- **路径**: `GET /api/mobile/public/rules`
- **描述**: 获取启用的规则图片数组。
- **响应数据**:
  ```json
  {
    "code": 200,
    "data": { "images": ["url1", "url2"] }
  }
  ```

### 获取客服列表

- **路径**: `GET /api/mobile/public/customer-services`
- **描述**: 获取所有启用的客服联系方式。
