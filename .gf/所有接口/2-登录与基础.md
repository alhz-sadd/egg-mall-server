# 登录与基础

> **核心业务声明与注意事项**：
>
> 1. 本模块包含了 A端(admin-inner)、B端(admin-outer) 和 C端(mobile) 的登录、登出、获取当前用户信息、修改密码、谷歌验证器以及 Token 刷新等基础接口。
> 2. 所有账号（A端平台、B端商户/店长、C端用户）均统一存放在 `sys_user` 表，通过 `user_type` 进行身份隔离：
>    - `user_type = 1`: 系统管理员 (A端)
>    - `user_type = 2`: 商家/店长 (B端)
>    - `user_type = 3`: 业务员 (B端/A端可见)
>    - `user_type = 4`: C端普通用户
>
> **涉及的数据表**：
>
> - `sys_user` (全平台统一用户账号表)
> - `sys_role` (角色表)
> - `sys_menu` (菜单表)
> - `sys_role_menu` (角色菜单关联表)
> - `user_wallet` (C端用户钱包表)

## 1. A端 (Admin-Inner) 平台管理端

### [A端登录]

- **路径**: `POST /api/admin-inner/login`
- **描述**: A 端总后台平台管理员登录，换取身份 Token。
- **请求头 (Headers)**: 无需鉴权
- **请求参数 (Body)**:| 字段名   | 类型   | 必填 | 描述                     |
  | -------- | ------ | ---- | ------------------------ |
  | username | string | 是   | 用户名/账号              |
  | password | string | 是   | 密码                     |
  | code     | string | 否   | 谷歌验证码（如果已绑定） |
- **响应数据**:
  ```json
  {
    "code": 200,
    "message": "登录成功",
    "data": {
      "token": "eyJhbGciOiJIUzI1NiIsInR5cCI...",
      "username": "admin"
    }
  }
  ```

### [A端获取当前用户信息]

- **路径**: `GET /api/admin-inner/current`
- **描述**: 获取 A 端当前登录管理员的个人信息、角色、菜单权限以及商铺信息。
- **请求头 (Headers)**:
  - `Authorization`: `Bearer <token>`
- **请求参数**: 无
- **响应数据**:
  ```json
  {
    "code": 200,
    "message": "获取成功",
    "data": {
      "user_id": 1,
      "username": "admin",
      "user_type": "system",
      "menus": ["dashboard", "system:user:list"],
      "google_auth_bind": 1
    }
  }
  ```

### [A端登出]

- **路径**: `POST /api/admin-inner/logout`
- **描述**: A 端管理员退出登录，清理服务器缓存或执行注销逻辑。
- **请求头 (Headers)**:
  - `Authorization`: `Bearer <token>`
- **请求参数**: 无
- **响应数据**:
  ```json
  {
    "code": 200,
    "message": "退出成功",
    "data": null
  }
  ```

### [A端修改个人密码]

- **路径**: `PUT /api/admin-inner/profile/updatePwd`
- **描述**: A 端管理员修改自己的登录密码。
- **请求头 (Headers)**:
  - `Authorization`: `Bearer <token>`
- **请求参数 (Body)**:| 字段名       | 类型   | 必填 | 描述   |
  | ------------ | ------ | ---- | ------ |
  | old_password | string | 是   | 原密码 |
  | new_password | string | 是   | 新密码 |
- **响应数据**:
  ```json
  {
    "code": 200,
    "message": "密码修改成功，请重新登录",
    "data": null
  }
  ```

### [A端绑定/重置谷歌验证]

- **路径**: `POST /api/admin-inner/profile/resetGoogle`
- **描述**: 重新生成并绑定/重置当前管理员的谷歌验证码 (Google Authenticator) 密钥。
- **请求头 (Headers)**:
  - `Authorization`: `Bearer <token>`
- **请求参数**: 视业务需求传入旧验证码等
- **响应数据**:
  ```json
  {
    "code": 200,
    "message": "重置成功",
    "data": {
      "secret": "JBSWY3DPEHPK3PXP",
      "qrcode_url": "data:image/png;base64,..."
    }
  }
  ```

## 2. B端 (Admin-Outer) 商家端

### [B端登录]

- **路径**: `POST /api/admin-outer/login`
- **描述**: B 端商户及员工登录系统。
- **请求头 (Headers)**: 无需鉴权
- **请求参数 (Body)**:| 字段名   | 类型   | 必填 | 描述                     |
  | -------- | ------ | ---- | ------------------------ |
  | username | string | 是   | 用户名/账号              |
  | password | string | 是   | 密码                     |
  | code     | string | 否   | 谷歌验证码（如果已绑定） |
- **响应数据**:
  ```json
  {
    "code": 200,
    "message": "登录成功",
    "data": {
      "token": "eyJhbGciOiJIUzI1NiIsInR5cCI..."
    }
  }
  ```

### [B端获取当前用户信息]

- **路径**: `GET /api/admin-outer/current` (同时兼容 `GET /api/admin-outer/getUserInfo`)
- **描述**: 获取当前登录商户的个人基本信息、角色权限和绑定的店铺 (`shop_id`)。
- **请求头 (Headers)**:
  - `Authorization`: `Bearer <token>`
- **请求参数**: 无
- **响应数据**:
  ```json
  {
    "code": 200,
    "message": "获取成功",
    "data": {
      "user_id": 10,
      "username": "shop_test",
      "user_type": "merchant",
      "shop_id": 20
    }
  }
  ```

### [B端获取菜单权限]

- **路径**: `GET /api/admin-outer/getMenu`
- **描述**: 根据 B 端登录用户的角色（`role_id` / `user_type`）获取其被授权的动态菜单及按钮权限集合。
- **请求头 (Headers)**:
  - `Authorization`: `Bearer <token>`
- **请求参数**: 无
- **响应数据**:
  ```json
  {
    "code": 200,
    "message": "获取成功",
    "data": [
      "shop:dashboard:view",
      "shop:goods:list"
    ]
  }
  ```

### [B端登出]

- **路径**: `POST /api/admin-outer/logout`
- **描述**: B 端商户退出登录。
- **请求头 (Headers)**:
  - `Authorization`: `Bearer <token>`
- **请求参数**: 无
- **响应数据**:
  ```json
  {
    "code": 200,
    "message": "退出成功",
    "data": null
  }
  ```

## 3. C端 (Mobile) 移动端

c端注册时候，需要有默认的登录密码：123456，sys_user 表的withdraw_password，生成唯一的邀请码，也存在sys_user invite_code字段

- **描述**: C 端新用户注册。
- **请求头 (Headers)**: 无需鉴权
- **请求参数 (Body)**:| 字段名      | 类型   | 必填 | 描述        |


### [C端登录]

## 4. 全局公共接口

### [Token 无感刷新]

- **A端路径**: `POST /api/admin-inner/auth/refresh`
- **B端路径**: `POST /api/admin-outer/auth/refresh`
- **C端路径**: `POST /api/mobile/auth/refresh`
- **描述**: 当 Token 即将过期时，调用此接口换取新的 Token。
- **请求头 (Headers)**:
  - `Authorization`: `Bearer <旧token>`
- **请求参数**: 无
- **响应数据**:
  ```json
  {
    "code": 200,
    "message": "刷新成功",
    "data": {
      "token": "eyJhbGciOiJIUzI1NiIsInR5cCI..."
    }
  }
  ```
