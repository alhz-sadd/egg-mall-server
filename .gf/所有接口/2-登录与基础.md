# 登录与基础

> **核心业务声明与注意事项**：
>
> 1. 本模块包含了 A端(admin-inner)、B端(admin-outer) 和 C端(mobile) 的登录、登出、获取当前用户信息、修改密码、谷歌验证器以及 Token 刷新等基础接口。
> 2. 所有账号（A端平台、B端商户/店长、C端用户）均统一存放在 `sys_user` 表，通过 `user_type` 进行身份隔离：
>    - `user_type = 1`: 系统管理员 (A端)
>    - `user_type = 2`: 商家/店长 (B端)
>    - `user_type = 3`: 业务员 (B端/A端可见)
>    - `user_type = 4`: C端普通用户
>
> **涉及的数据表**：
>
> - `sys_user` (全平台统一用户账号表)
> - `sys_role` (角色表)
> - `sys_menu` (菜单表)
> - `sys_role_menu` (角色菜单关联表)
> - `user_wallet` (C端用户钱包表)

## 1. A端 (Admin-Inner) 平台管理端

### [A端登录]

- **路径**: `POST /api/admin-inner/login`
- **描述**: A 端总后台平台管理员登录，换取身份 Token。支持一步完成账号密码和谷歌验证码校验。
- **请求头 (Headers)**: 无需鉴权
- **请求参数 (Body)**:| 字段名   | 类型   | 必填 | 描述                     |
  | -------- | ------ | ---- | ------------------------ |
  | username | string | 是   | 用户名/账号              |
  | password | string | 是   | 密码                     |
  | googleCode | string | 否   | 谷歌验证码或恢复码（如果已绑定，第二次请求时必须携带） |
- **响应数据**:
  1. 登录成功（未绑定谷歌，或已传入正确的谷歌验证码），返回 `200` 状态码：
  ```json
  {
    "code": 200,
    "message": "登录成功",
    "data": {
      "accessToken": "eyJhbGciOiJIUzI1NiIsInR5cCI...",
      "refreshToken": "..."
    }
  }
  ```
  2. 账号密码正确但需要谷歌验证（未传入 `googleCode` 时），返回 `422` 状态码：
  ```json
  {
    "code": 422,
    "message": "需要进行谷歌验证",
    "data": {
      "need_totp": true,
      "userId": 1
    }
  }
  ```

### [A端获取当前用户信息]

- **路径**: `GET /api/admin-inner/current`
- **描述**: 获取 A 端当前登录管理员的个人信息、角色、菜单权限以及商铺信息。
- **请求头 (Headers)**:
  - `Authorization`: `Bearer <token>`
- **请求参数**: 无
- **响应数据**:
  ```json
  {
    "code": 200,
    "message": "获取成功",
    "data": {
      "user_id": 1,
      "username": "admin",
      "user_type": "system",
      "menus": ["dashboard", "system:user:list"],
      "isBindGoogle": true
    }
  }
  ```

### [A端登出]

- **路径**: `POST /api/admin-inner/logout`
- **描述**: A 端管理员退出登录，清理服务器缓存或执行注销逻辑。
- **请求头 (Headers)**:
  - `Authorization`: `Bearer <token>`
- **请求参数**: 无
- **响应数据**:
  ```json
  {
    "code": 200,
    "message": "退出成功",
    "data": null
  }
  ```

### [A端修改个人资料]

- **路径**: `PUT /api/admin-inner/profile`
- **描述**: A端管理员修改自己的个人资料。所有字段均为选填。
- **请求头 (Headers)**: 
  - `Authorization`: `Bearer <token>`
- **请求参数 (Body)**:| 字段名 | 类型   | 必填 | 描述 |
  | ------ | ------ | ---- | ---- |
  | nickname | string | 否   | 昵称 |
  | phone    | string | 否   | 手机号 |
  | email    | string | 否   | 邮箱 |
  | gender   | number | 否   | 性别 (0未知 1男 2女) |
- **响应数据**:
  ```json
  {
    "code": 200,
    "message": "修改个人资料成功",
    "data": null
  }
  ```

### [A端给其他用户重置密码]

- **路径**: `PUT /api/admin-inner/users/reset-pwd`
- **描述**: A端管理员修改其他用户（店长、业务员、C端用户）的登录密码。
- **请求头 (Headers)**: 
  - `Authorization`: `Bearer <token>`
- **请求参数 (Body)**:| 字段名 | 类型   | 必填 | 描述 |
  | ------ | ------ | ---- | ---- |
  | userId | number | 是   | 需要修改密码的用户ID |
  | newPassword | string | 是   | 新密码 |
- **响应数据**:
  ```json
  {
    "code": 200,
    "message": "用户密码重置成功",
    "data": null
  }
  ```

### [A端修改个人密码]

- **路径**: `PUT /api/admin-inner/profile/updatePwd`
- **描述**: A 端管理员修改自己的登录密码。
- **请求头 (Headers)**:
  - `Authorization`: `Bearer <token>`
- **请求参数 (Body)**:| 字段名       | 类型   | 必填 | 描述   |
  | ------------ | ------ | ---- | ------ |
  | oldPassword | string | 是   | 原密码 |
  | newPassword | string | 是   | 新密码 |
  | confirmPassword | string | 是   | 确认密码 |
- **响应数据**:
  ```json
  {
    "code": 200,
    "message": "密码修改成功，请重新登录",
    "data": null
  }
  ```

谷歌验证相关接口

### [A端绑定谷歌：验证密码]

- **路径**: `POST /api/admin-inner/totp/verify-password`
- **描述**: 绑定谷歌验证码前，验证账号和密码，获取一次性绑定授权凭证 `bindToken`。
- **请求头 (Headers)**: 无需鉴权
- **请求参数 (Body)**:| 字段名 | 类型   | 必填 | 描述 |
  | ------ | ------ | ---- | ---- |
  | username | string | 是   | 账号 |
  | password | string | 是   | 密码 |
- **响应数据**:
  ```json
  {
    "code": 200,
    "message": "密码验证成功，可获取二维码",
    "data": {
      "bindToken": "abcd1234efgh5678..."
    }
  }
  ```

### [A端绑定谷歌：获取二维码]

- **路径**: `POST /api/admin-inner/totp/bind-init`
- **描述**: 根据第一步获取的 `bindToken`，生成绑定谷歌验证码的二维码。
- **请求头 (Headers)**: 无需鉴权
- **请求参数 (Body)**:| 字段名 | 类型   | 必填 | 描述 |
  | ------ | ------ | ---- | ---- |
  | bindToken | string | 是   | 上一步获取的绑定凭证 |
- **响应数据**:
  ```json
  {
    "code": 200,
    "message": "获取二维码成功",
    "data": {
      "qrCodeUrl": "data:image/png;base64,..."
    }
  }
  ```

### [A端绑定谷歌：确认绑定]

- **路径**: `POST /api/admin-inner/totp/bind-confirm`
- **描述**: 输入谷歌验证码确认绑定，成功后返回一次性恢复码。
- **请求头 (Headers)**: 无需鉴权
- **请求参数 (Body)**:| 字段名 | 类型   | 必填 | 描述 |
  | ------ | ------ | ---- | ---- |
  | bindToken | string | 是   | 第一步获取的绑定凭证 |
  | code   | string | 是   | 6位谷歌验证码 |
- **响应数据**:
  ```json
  {
    "code": 200,
    "message": "绑定成功，请妥善保存恢复码",
    "data": {
      "recoveryCodes": ["ABCD1234", "EFGH5678", "..."]
    }
  }
  ```

### [A端登录第二步：谷歌验证]

- **路径**: `POST /api/admin-inner/totp/login-verify`
- **描述**: 账号密码验证通过后，如果开启了谷歌验证，调用此接口完成登录。
- **请求头 (Headers)**: 无需鉴权
- **请求参数 (Body)**:| 字段名    | 类型   | 必填 | 描述 |
  | --------- | ------ | ---- | ---- |
  | userId    | number | 是   | 用户ID |
  | inputCode | string | 是   | 6位谷歌验证码或8位恢复码 |
- **响应数据**:
  ```json
  {
    "code": 200,
    "message": "登录成功",
    "data": {
      "accessToken": "...",
      "refreshToken": "..."
    }
  }
  ```

### [A端自行解绑谷歌]

- **路径**: `POST /api/admin-inner/totp/unbind`
- **描述**: 已经登录的用户，自行验证当前登录密码和谷歌验证码以解绑谷歌验证。
- **请求头 (Headers)**:
  - `Authorization`: `Bearer <token>`
- **请求参数 (Body)**:| 字段名 | 类型   | 必填 | 描述 |
  | ------ | ------ | ---- | ---- |
  | password | string | 是   | 当前登录密码 |
  | code   | string | 是   | 6位谷歌动态验证码 (不支持恢复码) |
- **响应数据**:
  ```json
  {
    "code": 200,
    "message": "解绑谷歌验证码成功",
    "data": null
  }
  ```

### [A端给其他用户重置谷歌验证码]

- **路径**: `PUT /api/admin-inner/users/reset-google`
- **描述**: A端管理员强制重置其他用户（店长、业务员）的谷歌验证码。重置后，目标用户状态变为“未绑定”，下次登录无需验证码。
- **请求头 (Headers)**:
  - `Authorization`: `Bearer <token>`
- **请求参数 (Body)**:| 字段名   | 类型   | 必填 | 描述                               |
  | -------- | ------ | ---- | ---------------------------------- |
  | userId | number | 是   | 需要重置的用户ID                       |
- **响应数据**:
  ```json
  {
    "code": 200,
    "message": "用户谷歌验证码重置成功",
    "data": null
  }
  ```

## 3. C端 (Mobile) 移动端

c端注册时候，需要有默认的登录密码：123456，sys_user 表的withdraw_password，生成唯一的邀请码，也存在sys_user invite_code字段
