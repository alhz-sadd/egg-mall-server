# 充提渠道管理模块

## A端 (Admin-Inner) 平台渠道模板管理

### 获取平台充提渠道模板列表

- **路径**: `GET /api/admin-inner/pay-channels`
- **描述**: A端获取全局配置的充提渠道模板列表 (shop_id = 0)
- **请求头 (Headers)**:
  - `Authorization`: `Bearer <token>`
- **请求参数 (Query)**:

| 字段名           | 类型 | 必填 | 描述                  |
| :--------------- | :--- | :--- | :-------------------- |
| `channel_type` | int  | 否   | 渠道类型：1充值 2提现 |
| `is_enable`    | int  | 否   | 状态：0关闭 1启用     |
| `page`         | int  | 否   | 页码                  |
| `page_size`    | int  | 否   | 每页数量              |

- **响应数据**:
  ```json
  {
    "code": 200,
    "message": "success",
    "data": {
      "total": 10,
      "list": [
        {
          "id": 1,
          "shop_id": 0,
          "channel_type": 1,
          "channel_code": "usdt_trc20",
          "channel_name": "USDT-TRC20",
          "is_platform_default": 1,
          "is_enable": 1,
          "sort": 0,
          "remark": ""
        }
      ]
    }
  }
  ```

### 新增平台充提渠道模板

- **路径**: `POST /api/admin-inner/pay-channels`
- **描述**: A端新增充提渠道模板，新建店铺时会自动复制这些模板
- **请求头 (Headers)**:
  - `Authorization`: `Bearer <token>`
- **请求参数 (Body)**:

| 字段名           | 类型   | 必填 | 描述                          |
| :--------------- | :----- | :--- | :---------------------------- |
| `channel_type` | int    | 是   | 渠道类型：1充值 2提现         |
| `channel_code` | string | 是   | 渠道编码，如 "alipay_01"      |
| `channel_name` | string | 是   | 前端展示名称，如 "支付宝转账" |
| `is_enable`    | int    | 否   | 状态：0关闭 1启用，默认1      |
| `sort`         | int    | 否   | 排序，默认0                   |
| `remark`       | string | 否   | 备注                          |

### 修改平台充提渠道模板

- **路径**: `PUT /api/admin-inner/pay-channels/:id`
- **描述**: A端修改充提渠道模板
- **请求头 (Headers)**:
  - `Authorization`: `Bearer <token>`
- **请求参数 (Path)**:
  - `id` (int): 渠道模板ID
- **请求参数 (Body)**:

| 字段名           | 类型   | 必填 | 描述              |
| :--------------- | :----- | :--- | :---------------- |
| `channel_code` | string | 否   | 渠道编码          |
| `channel_name` | string | 否   | 前端展示名称      |
| `is_enable`    | int    | 否   | 状态：0关闭 1启用 |
| `sort`         | int    | 否   | 排序              |
| `remark`       | string | 否   | 备注              |

### 删除平台充提渠道模板

- **路径**: `DELETE /api/admin-inner/pay-channels/:id`
- **描述**: A端删除充提渠道模板
- **请求头 (Headers)**:
  - `Authorization`: `Bearer <token>`
- **请求参数 (Path)**:
  - `id` (int): 渠道模板ID

### 同步平台默认渠道到指定店铺

- **路径**: `POST /api/admin-inner/pay-channels/bind-shop`
- **描述**: A端手动给指定店铺绑定/更新平台最新的默认充提渠道模板
- **请求头 (Headers)**:
  - `Authorization`: `Bearer <token>`
- **请求参数 (Body)**:

| 字段名      | 类型 | 必填 | 描述                 |
| :---------- | :--- | :--- | :------------------- |
| `shop_id` | int  | 是   | 需要同步的目标店铺ID |

## B端 (Admin-Outer) 店铺充提渠道管理

- **路径**: `GET /api/admin-outer/pay-channels`
- **描述**: B端获取充提渠道列表，仅返回本店铺数据

- **请求参数 (Query)**:

| 字段名           | 类型 | 必填 | 描述                  |
| :--------------- | :--- | :--- | :-------------------- |
| `channel_type` | int  | 否   | 渠道类型：1充值 2提现 |
| `is_enable`    | int  | 否   | 状态：0关闭 1启用     |
| `page`         | int  | 否   | 页码                  |
| `page_size`    | int  | 否   | 每页数量              |

- **响应数据**:
  ```json
  {
    "code": 200,
    "message": "success",
    "data": {
      "total": 10,
      "list": [
        {
          "id": 1,
          "shop_id": 1001,
          "channel_type": 1,
          "channel_code": "usdt_trc20",
          "channel_name": "USDT-TRC20",
          "is_platform_default": 1,
          "is_enable": 1,
          "sort": 0,
          "remark": ""
        }
      ]
    }
  }
  ```

## 店铺修改充提渠道

- **路径**: `PUT /api/admin-outer/pay-channels/:id`
- **描述**: B端修改充提渠道。注意：平台预设的渠道（is_platform_default=1）不可修改 channel_code。
- **请求头 (Headers)**:
  - `Authorization`: `Bearer <token>`
- **请求参数 (Path)**:
  - `id` (int): 渠道ID
- **请求参数 (Body)**:

| 字段名           | 类型   | 必填 | 描述              |
| :--------------- | :----- | :--- | :---------------- |
| `channel_code` | string | 否   | 渠道编码          |

| `is_enable`    | int    | 否   | 状态：0关闭 1启用 |
| `sort`         | int    | 否   | 排序              |
| `remark`       | string | 否   | 备注              |

## 店铺删除充提渠道

- **路径**: `DELETE /api/admin-outer/pay-channels/:id`
- **描述**: B端删除充提渠道。注意：平台预设的渠道（is_platform_default=1）不允许删除。
- **请求头 (Headers)**:
  - `Authorization`: `Bearer <token>`
- **请求参数 (Path)**:
  - `id` (int): 渠道ID
