# 业务员管理接口文档

业务员管理模块主要负责对系统中的 **主管 (Role 2)** 和 **业务员 (Role 3)** 账号进行维护。该模块实现了权限隔离：管理员可管理所有主管和业务员，而主管仅能管理其名下绑定的业务员。

## 关联数据库表

- **admin_users**: 核心表，存储账号信息（ID、用户名、角色、状态、绑定关系等）。
- **operation_logs**: 操作日志表，记录增删改等敏感操作的流水。

---

## 1. 获取业务员/主管列表

**接口地址**：`/api/admin/salespersons`
**请求方式**：`GET`
**接口描述**：分页查询系统中的主管和业务员账号。管理员可查看全部，主管仅查看绑定的业务员。

### 请求参数 (Query)

| 参数名     | 类型    | 是否必填 | 描述                                     |
| :--------- | :------ | :------- | :--------------------------------------- |
| keyword    | String  | 否       | 关键词（匹配账号或昵称）                 |
| username   | String  | 否       | 登录账号（模糊匹配）                     |
| phone      | String  | 否       | 手机号（模糊匹配）                       |
| role       | Integer | 否       | 角色过滤：2主管 3业务员                  |
| status     | Integer | 否       | 状态过滤：1启用 0禁用                    |
| start_time | String  | 否       | 创建时间开始（YYYY-MM-DD）               |
| end_time   | String  | 否       | 创建时间结束（YYYY-MM-DD）               |
| page       | Integer | 否       | 当前页码（默认 1）                       |
| page_size  | Integer | 否       | 每页显示条数（默认 10）                  |

### 接口返回

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "list": [
      {
        "id": 10,
        "username": "sales01",
        "nickname": "业务员01",
        "role": 3,
        "status": 1,
        "bind_salesperson_id": 5,
        "createdAt": "2026-08-16T10:00:00.000Z"
      }
    ],
    "total": 1
  }
}
```

## 2. 获取业务员/主管详情

**接口地址**：`/api/admin/salespersons/:id`
**请求方式**：`GET`
**接口描述**：查看特定主管或业务员的详细资料。

### 请求参数 (Path)

| 参数名 | 类型    | 是否必填 | 描述   |
| :----- | :------ | :------- | :----- |
| id     | Integer | 是       | 账号ID |

### 接口返回

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "id": 10,
    "username": "sales01",
    "nickname": "业务员01",
    "phone": "13800000000",
    "role": 3,
    "status": 1,
    "remark": "测试业务员"
  }
}
```

## 3. 新增业务员/主管

**接口地址**：`/api/admin/salespersons`
**请求方式**：`POST`
**接口描述**：创建新的主管或业务员账号。系统会自动记录操作日志。

### 请求参数 (Body)

| 参数名              | 类型    | 是否必填 | 描述                             |
| :------------------ | :------ | :------- | :------------------------------- |
| username            | String  | 是       | 登录账号                         |
| password            | String  | 是       | 登录密码                         |
| nickname            | String  | 否       | 昵称                             |
| role                | Integer | 是       | 角色：2主管 3业务员              |
| phone               | String  | 否       | 手机号                           |
| status              | Integer | 否       | 状态：1启用 0禁用                |
| bind_salesperson_id | Integer | 否       | 绑定上级主管ID（业务员必填）     |

### 接口返回

```json
{
  "code": 200,
  "message": "创建成功",
  "data": { "id": 11, "username": "new_sales" }
}
```

---

## 4. 更新业务员/主管

**接口地址**：`/api/admin/salespersons/:id`
**请求方式**：`PUT`
**接口描述**：修改主管或业务员的信息。仅允许操作角色为 2 或 3 的账号。

### 请求参数 (Path + Body)

| 参数名   | 类型    | 是否必填 | 描述                               |
| :------- | :------ | :------- | :--------------------------------- |
| id       | Integer | 是       | (Path) 账号ID                      |
| nickname | String  | 否       | (Body) 新昵称                      |
| phone    | String  | 否       | (Body) 新手机号                    |
| status   | Integer | 否       | (Body) 状态：1启用 0禁用           |
| password | String  | 否       | (Body) 新密码（留空则不修改）      |

---

## 5. 删除/批量删除业务员

**单条删除**：`DELETE /api/admin/salespersons/:id`
**批量删除**：`POST /api/admin/salespersons/batch-delete`

### 请求参数 (批量删除 Body)

| 参数名 | 类型  | 是否必填 | 描述       |
| :----- | :---- | :------- | :--------- |
| ids    | Array | 是       | 账号ID数组 |

### 接口返回

```json
{
  "code": 200,
  "message": "删除成功",
  "data": null
}
```
