# 菜单管理接口文档

## 1. 获取所有菜单树

**接口地址**：`/api/admin/system/menu/getAllMenuTree`
**请求方式**：`GET`
**接口描述**：获取系统中所有的前端路由菜单列表，并以树形结构返回。

### 请求参数

无

### 请求头

| 参数名        | 类型   | 是否必填 | 描述                     |
| :------------ | :----- | :------- | :----------------------- |
| Authorization | String | 是       | 格式为`Bearer {token}` |

### 接口返回

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": [
    {
      "id": 1,
      "parent_id": null,
      "name": "System",
      "path": "/system",
      "component": "Layout",
      "redirect": null,
      "hidden": false,
      "alwaysShow": true,
      "meta": {
        "title": "系统管理",
        "icon": "system"
      },
      "sort": 1,
      "type": 0,
      "is_ext": false,
      "keep_alive": true,
      "status": 0,
      "permission": "system:manage",
      "is_frame": 1,
      "is_cache": 0,
      "visible": 0,
      "perms": "system:manage",
      "children": [
        {
          "id": 2,
          "parent_id": 1,
          "name": "Menu",
          "path": "menu",
          "component": "system/menu/index",
          "meta": {
            "title": "菜单管理",
            "icon": "menu"
          },
          "sort": 1,
          "type": 1,
          "status": 0,
          "permission": "system:menu:list",
          "children": []
        }
      ]
    }
  ]
}
```

### 返回字段说明

| 字段名            | 类型   | 描述                          |
| :---------------- | :----- | :---------------------------- |
| code              | Number | 状态码，200 表示成功          |
| msg               | String | 提示信息                      |
| data              | Array  | 菜单树数据数组                |
| data[].id         | Number | 菜单ID                        |
| data[].parent_id  | Number | 父级菜单ID                    |
| data[].name       | String | 路由名称                      |
| data[].path       | String | 路由路径                      |
| data[].component  | String | 组件路径                      |
| data[].meta       | Object | 路由元信息（标题、图标等）    |
| data[].sort       | Number | 显示顺序                      |
| data[].type       | Number | 菜单类型（0目录 1菜单 2按钮） |
| data[].status     | Number | 菜单状态（0正常 1停用）       |
| data[].permission | String | 权限标识                      |
| data[].children   | Array  | 子菜单列表                    |

## 2. 获取用户动态路由树

**接口地址**：`/api/admin/getRouters`
**请求方式**：`GET`
**接口描述**：根据当前登录管理员的权限，返回其有权访问的动态路由菜单树。该接口仅返回目录(type=0)和菜单(type=1)，过滤掉按钮(type=2)。

### 请求参数

无

### 请求头

| 参数名        | 类型   | 是否必填 | 描述                     |
| :------------ | :----- | :------- | :----------------------- |
| Authorization | String | 是       | 格式为`Bearer {token}` |

### 接口返回

```json
{
  "msg": "操作成功",
  "code": 200,
  "data": [
    {
      "name": "System",
      "path": "/system",
      "hidden": false,
      "component": "Layout",
      "meta": {
        "title": "系统管理",
        "icon": "system",
        "noCache": false,
        "link": null
      },
      "children": [
        {
          "name": "User",
          "path": "user",
          "hidden": false,
          "component": "system/user/index",
          "meta": {
            "title": "用户管理",
            "icon": "user",
            "noCache": false,
            "link": null
          }
        }
      ]
    }
  ]
}
```

### 返回字段说明

| 字段名              | 类型    | 描述                             |
| :------------------ | :------ | :------------------------------- |
| msg                 | String  | 提示信息                         |
| code                | Number  | 状态码，200 表示成功             |
| data                | Array   | 路由树数据数组                   |
| data[].name         | String  | 路由名称                         |
| data[].path         | String  | 路由地址                         |
| data[].hidden       | Boolean | 是否隐藏路由                     |
| data[].component    | String  | 组件路径                         |
| data[].meta         | Object  | 路由元信息                       |
| data[].meta.title   | String  | 路由标题                         |
| data[].meta.icon    | String  | 路由图标                         |
| data[].meta.noCache | Boolean | 是否不缓存（对应`keep_alive`） |
| data[].meta.link    | String  | 外链地址（如果是外链）           |
| data[].children     | Array   | 子路由列表                       |

## 3. 获取角色已勾选菜单 ID 数组

**接口地址**：`/api/admin/system/role/getRoleMenuIds`
**请求方式**：`GET`
**接口描述**：获取指定角色已勾选的菜单 ID 数组。该接口返回的 ID 数组直接对应 `1. 获取所有菜单树 (getAllMenuTree)` 接口中返回的菜单项 `id` 字段，用于前端在权限分配界面实现“回显勾选”功能。

### 请求参数

| 参数名 | 类型   | 是否必填 | 描述    |
| :----- | :----- | :------- | :------ |
| roleId | Number | 是       | 角色 ID |

### 请求头

| 参数名        | 类型   | 是否必填 | 描述                     |
| :------------ | :----- | :------- | :----------------------- |
| Authorization | String | 是       | 格式为`Bearer {token}` |

### 接口返回

```json
{
  "msg": "操作成功",
  "code": 200,
  "data": [1, 2, 100, 101]
}
```

### 返回字段说明

| 字段名 | 类型   | 描述                                                         |
| :----- | :----- | :----------------------------------------------------------- |
| msg    | String | 提示信息                                                     |
| code   | Number | 状态码，200 表示成功                                         |
| data   | Array  | 已勾选的菜单 ID 数组（对应`getAllMenuTree` 返回的 `id`） |

---

## 4. 新增角色

**接口地址**：`/api/admin/role`
**请求方式**：`POST`
**接口描述**：创建新的角色，并可选地关联初始菜单权限。

### 请求参数

| 参数名            | 类型    | 是否必填 | 描述                                       |
| :---------------- | :------ | :------- | :----------------------------------------- |
| roleName          | String  | 是       | 角色名称                                   |
| roleKey           | String  | 是       | 权限字符                                   |
| roleSort          | Number  | 否       | 显示顺序（默认 0）                         |
| status            | String  | 否       | 角色状态（0正常 1停用，默认 0）            |
| menuCheckStrictly | Boolean | 否       | 菜单树选择项是否关联显示（默认 true）      |
| remark            | String  | 否       | 备注                                       |
| menuIds           | Array   | 否       | 初始关联的菜单 ID 数组                     |

### 请求头

| 参数名        | 类型   | 是否必填 | 描述                     |
| :------------ | :----- | :------- | :----------------------- |
| Authorization | String | 是       | 格式为`Bearer {token}` |

### 接口返回

```json
{
  "code": 200,
  "msg": "新增成功",
  "data": {
    "id": 3,
    "roleName": "业务员",
    "roleKey": "salesperson",
    "roleSort": 3,
    "status": "0",
    "menuCheckStrictly": true,
    "remark": "业务员角色",
    "createBy": "admin",
    "createdAt": "2024-03-21T09:00:00.000Z",
    "updatedAt": "2024-03-21T09:00:00.000Z"
  }
}
```

### 返回字段说明

| 字段名 | 类型   | 描述                 |
| :----- | :----- | :------------------- |
| code   | Number | 状态码，200 表示成功 |
| msg    | String | 提示信息             |
| data   | Object | 新增的角色对象       |

---

## 5. 修改角色权限

**接口地址**：`/api/admin/role/:id`
**请求方式**：`PUT`
**接口描述**：修改指定角色的基本信息及菜单权限关联。通过传入 `menuIds` 数组，可以同步更新角色在 `role_menus` 表和 `role_permissions` 表中的权限数据。

### 请求参数

| 参数名            | 类型    | 是否必填 | 描述                                       |
| :---------------- | :------ | :------- | :----------------------------------------- |
| roleName          | String  | 否       | 角色名称                                   |
| roleKey           | String  | 否       | 权限字符                                   |
| roleSort          | Number  | 否       | 显示顺序                                   |
| status            | String  | 否       | 角色状态（0正常 1停用）                    |
| menuCheckStrictly | Boolean | 否       | 菜单树选择项是否关联显示                   |
| remark            | String  | 否       | 备注                                       |
| menuIds           | Array   | 否       | 菜单 ID 数组，用于修改角色拥有的菜单权限 |

### 请求头

| 参数名        | 类型   | 是否必填 | 描述                     |
| :------------ | :----- | :------- | :----------------------- |
| Authorization | String | 是       | 格式为`Bearer {token}` |

### 接口返回

```json
{
  "code": 200,
  "msg": "修改成功",
  "data": {
    "id": 2,
    "roleName": "主管",
    "roleKey": "supervisor",
    "roleSort": 2,
    "status": "0",
    "menuCheckStrictly": true,
    "remark": "主管角色",
    "updateBy": "admin",
    "updatedAt": "2024-03-21T08:00:00.000Z"
  }
}
```

### 返回字段说明

| 字段名 | 类型   | 描述                 |
| :----- | :----- | :------------------- |
| code   | Number | 状态码，200 表示成功 |
| msg    | String | 提示信息             |
| data   | Object | 更新后的角色对象     |
