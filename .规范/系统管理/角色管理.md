# 角色管理接口文档

角色管理模块用于维护系统中的权限角色，通过为角色分配不同的菜单权限，实现对管理员功能的精细化控制。

## 关联数据库表

- **roles**: 存储角色的基本信息（名称、标识、排序、状态等）。
- **role_menus**: 存储角色与菜单的关联关系，用于前端回显勾选。
- **role_permissions**: 存储角色与具体权限标识符的关联关系，用于后端鉴权。
- **menus**: 菜单资源表，提供权限分配的树形结构数据。

---

## 1. 获取角色列表

**接口地址**：`/api/admin/role`
**请求方式**：`GET`
**接口描述**：分页查询系统中的角色列表，支持按名称、标识和状态过滤。

### 请求参数 (Query)

| 参数名   | 类型    | 是否必填 | 描述                 |
| :------- | :------ | :------- | :------------------- |
| pageNum  | Integer | 否       | 当前页码（默认 1）   |
| pageSize | Integer | 否       | 每页条数（默认 10）  |
| roleName | String  | 否       | 角色名称（模糊匹配） |
| roleKey  | String  | 否       | 权限标识（模糊匹配） |
| status   | String  | 否       | 状态：0正常 1停用    |

### 接口返回

```json
{
  "code": 200,
  "msg": "查询成功",
  "total": 1,
  "rows": [
    {
      "roleId": 1,
      "roleName": "超级管理员",
      "roleKey": "admin",
      "roleSort": 1,
      "status": "0",
      "menuIds": [1, 2, 3],
      "permissions": ["*:*:*"]
    }
  ]
}
```

---

## 2. 获取角色详情

**接口地址**：`/api/admin/role/:id`
**请求方式**：`GET`
**接口描述**：查看特定角色的详细信息及其拥有的菜单 ID 列表。

### 请求参数 (Path)

| 参数名 | 类型    | 是否必填 | 描述   |
| :----- | :------ | :------- | :----- |
| id     | Integer | 是       | 角色ID |

---

## 3. 新增角色

**接口地址**：`/api/admin/role`
**请求方式**：`POST`
**接口描述**：创建新角色，并可同步分配菜单权限。

### 请求参数 (Body)

| 参数名            | 类型    | 是否必填 | 描述                     |
| :---------------- | :------ | :------- | :----------------------- |
| roleName          | String  | 是       | 角色名称                 |
| roleKey           | String  | 是       | 权限标识（如 common）    |
| roleSort          | Number  | 否       | 显示顺序                 |
| status            | String  | 否       | 状态：0正常 1停用        |
| menuCheckStrictly | Boolean | 否       | 菜单树选择项是否关联显示 |
| menuIds           | Array   | 否       | 关联的菜单 ID 数组       |

---

## 4. 修改角色权限

**接口地址**：`/api/admin/role/:id`
**请求方式**：`PUT`
**接口描述**：修改角色基本信息及菜单权限关联。

### 请求参数 (Path + Body)

| 参数名   | 类型    | 是否必填 | 描述                                |
| :------- | :------ | :------- | :---------------------------------- |
| id       | Integer | 是       | (Path) 角色ID                       |
| roleName | String  | 否       | (Body) 角色名称                     |
| menuIds  | Array   | 否       | (Body) 菜单 ID 数组，同步更新权限表 |

---

## 5. 删除角色

**接口地址**：`/api/admin/role/:id`
**请求方式**：`DELETE`
**接口描述**：逻辑删除角色，支持批量删除（ID 逗号分隔）。超级管理员角色禁止删除。

---

## 6. 获取角色已勾选菜单 ID

**接口地址**：`/api/admin/system/role/getRoleMenuIds`
**请求方式**：`GET`
**接口描述**：查询指定角色已绑定的菜单 ID 数组，用于前端回显勾选状态。

### 请求参数 (Query)

| 参数名 | 类型    | 是否必填 | 描述   |
| :----- | :------ | :------- | :----- |
| roleId | Integer | 是       | 角色ID |
