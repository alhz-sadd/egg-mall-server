# 后台管理系统 - 个人中心接口文档

本文档整理了管理端（后台系统）当前登录用户（管理员/主管/业务员）在个人中心页面常用的接口，主要包括获取个人资料、修改基础资料以及修改登录密码。

所有接口均需携带 JWT Token 鉴权（Header: `Authorization: Bearer <token>`）。

---

## 1. 获取登录用户资料

用于在个人中心页面展示当前登录用户的基本信息及角色信息。

- **接口路径**: `GET /api/admin/system/user/profile`
- **请求方式**: `GET`
- **请求头**: `Authorization: Bearer <admin_token>`
- **请求参数**: 无

### 响应示例

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    "user": {
      "userId": 1,
      "userName": "admin",
      "nickName": "超级管理员",
      "email": "admin@example.com",
      "phonenumber": "13800138000",
      "sex": "1",          // 性别: '1'男, '2'女, '0'未知
      "avatar": "",
      "remark": "系统默认",
      "admin": true,       // 是否为超级管理员
      "roleId": 1,
      "isBindGoogle": true // 是否已绑定谷歌验证码
    },
    "roleGroup": "管理员", // 角色名称（管理员/主管/业务员）
    "postGroup": ""
  }
}
```

---

## 2. 修改基础资料

用于修改当前登录用户的昵称、手机号、邮箱、性别等。系统会自动同步更新对应移动端账号的基础资料（如有关联）。

- **接口路径**: `PUT /api/admin/system/user/profile`
- **请求方式**: `PUT`
- **请求头**: `Authorization: Bearer <admin_token>`
- **Content-Type**: `application/json`

### 请求参数 (Body)

| 参数名          | 类型   | 必填 | 说明                         |
| --------------- | ------ | ---- | ---------------------------- |
| `nickName`    | string | 否   | 昵称                         |
| `phonenumber` | string | 否   | 手机号                       |
| `email`       | string | 否   | 邮箱                         |
| `sex`         | string | 否   | 性别 ('0'未知, '1'男, '2'女) |

### 响应示例

```json
{
  "code": 200,
  "msg": "修改成功"
}
```

---

## 3. 修改登录密码

用于修改当前登录用户的密码。修改成功后会自动同步更新对应移动端账号的登录密码（如有关联）。

- **接口路径**: `PUT /api/admin/system/user/profile/updatePwd`
- **请求方式**: `PUT`
- **请求头**: `Authorization: Bearer <admin_token>`
- **Content-Type**: `application/json`

### 请求参数 (Body)

| 参数名              | 类型   | 必填 | 说明                                 |
| ------------------- | ------ | ---- | ------------------------------------ |
| `oldPassword`     | string | 是   | 当前使用的旧密码                     |
| `newPassword`     | string | 是   | 新密码                               |
| `confirmPassword` | string | 是   | 确认新密码 (必须与 newPassword 一致) |

### 响应示例

```json
{
  "code": 200,
  "msg": "密码修改成功"
}
```

### 错误响应示例

- 当旧密码错误时：

```json
{
  "code": 422,
  "msg": "修改密码失败，旧密码错误"
}
```

- 当两次输入密码不一致时：

```json
{
  "code": 422,
  "msg": "两次输入的新密码不一致"
}
```
