# 管理端登录与菜单获取流程

本文档详细说明了管理系统从登录到获取用户信息、权限及左侧菜单树的完整业务流程。系统采用 BFF 模式，兼容 RuoYi 前端架构。

---

## 1. 管理员登录 (Authentication)

**接口地址**：`POST /api/admin/login`
**核心逻辑**：
1. **身份校验**：控制器解析客户端环境（IP、设备、浏览器等），Service 层校验账号是否存在、状态是否正常（`status=1`）及密码是否匹配。
2. **日志记录**：无论成功或失败，系统均会记录详细的登录日志到 `admin_login_logs` 表。
3. **Token 签发**：使用 JWT 签发令牌。若勾选“记住我”，有效期可延长至 30 天。

---

## 2. 获取用户信息与权限标识 (getInfo)

**接口地址**：`GET /api/admin/getInfo`
**核心逻辑**：
1. **获取基本资料**：从 `admin_users` 表获取当前登录管理员的头像、昵称、角色等信息。
2. **获取权限标识数组**：
   - 调用 `service.adminUser.getMenus` 获取当前管理员的权限字符串列表。
   - **全权限处理**：若用户名为 `333333` 或角色为 `admin (Role 1)`，系统会自动追加 `*:*:*` 标识，代表拥有所有接口操作权限。
3. **角色映射**：将数字角色（1/2/3）映射为前端识别的字符串（admin/supervisor/salesperson）。

---

## 3. 获取左侧路由菜单树 (getRouters)

**接口地址**：`GET /api/admin/getRouters`
**核心逻辑**：
1. **数据过滤**：
   - **超级管理员**：获取 `menus` 表中所有状态正常的记录。
   - **普通角色**：根据 `getInfo` 接口返回的权限标识符，过滤出该角色有权访问的菜单项。
2. **类型限制**：仅提取 **目录 (type=0)** 和 **菜单 (type=1)**，自动过滤掉按钮级权限（type=2），确保侧边栏只展示导航项。
3. **树形结构构建**：
   - 递归组装成嵌套的 JSON 结构。
   - 兼容 Vue Router 格式，包含 `path`, `component`, `meta` (title, icon, noCache) 等字段。
   - 支持外链（`is_ext` 字段判断）。

---

## 4. 获取所有侧边菜单 (系统管理专用)

**接口地址**：`GET /api/admin/system/menu/getAllMenuTree`
**接口描述**：该接口用于“菜单管理”页面，不受当前用户权限限制，返回系统中定义的**所有**原始菜单数据（包括按钮级权限），以供管理员进行菜单配置和权限分配。

---

## 权限获取流程图示

1. **前端请求**：用户提交登录表单 -> 获取 `token`。
2. **初始化请求**：前端使用 `token` 并发调用 `getInfo` 和 `getRouters`。
3. **后端处理**：
   - `AdminUser` -> `Role` -> `RolePermissions` (获取权限符数组)。
   - `Permissions` -> `Menus` (根据权限符过滤菜单记录)。
   - `Menus` -> `RouterTree` (转换为路由对象)。
4. **前端渲染**：前端将 `permissions` 存储在状态管理（Vuex/Pinia）中用于按钮显隐控制，将 `routerTree` 动态添加到路由表并渲染侧边栏。
