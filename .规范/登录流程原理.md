# 后台管理系统 - 登录与谷歌验证 (2FA) 完整流程说明

## 1. 验证原理 (TOTP)
本系统采用 **TOTP (Time-Based One-Time Password)** 即基于时间的一次性密码算法来实现谷歌验证功能。
- **核心库**: 
  - `speakeasy`: 用于生成 Base32 密钥 (Secret) 和验证 6 位动态验证码。
  - `qrcode`: 用于将生成的密钥转换为 `otpauth://` 协议的二维码图片 (Data URL)，方便用户使用 Google Authenticator、Microsoft Authenticator 等 App 扫码绑定。

## 2. 账号绑定状态说明
系统在管理员表 (`admin_users`) 中维护了 `google_code` 字段：
- **未绑定 (false)**: `google_code` 字段为空 (`null`)。
- **已绑定 (true)**: `google_code` 字段存有 Base32 密钥字符串。

## 3. 核心业务流程

### 3.1 登录流程
1. 前端调用 `POST /api/admin/login`，传入 `username`, `password` 以及可选的 `googleCode`。
2. 后端首先校验账号和密码是否正确。
3. **状态判断**:
   - 如果该账号的 `google_code` 为空，说明**未绑定**。此时直接放行，返回登录成功的 JWT Token。
   - 如果该账号的 `google_code` 不为空，说明**已绑定**。此时强制校验前端传来的 `googleCode` 参数。
4. **验证码校验**: 使用 `speakeasy.totp.verify()` 进行时间窗口校验，验证通过后发放 JWT Token，否则抛出“谷歌验证码错误”。

### 3.2 自行绑定流程
1. 对于**未绑定**的管理员，可以通过账号密码直接登录系统（也可以不登录直接在登录页进入绑定流程）。
2. 前端调用公开接口 `POST /api/admin/generate-google-auth`。为了账号安全，需要在请求体中提供当前账号的登录账号 (`username`) 和登录密码 (`password`) 进行二次确认。
3. 后端验证账号密码是否匹配，验证通过后生成专属的 Secret 密钥，将其存入**服务端 Redis 缓存**（有效期 5 分钟），此时不保存到数据库。
4. 接口返回 `qrCodeUrl` (Base64 格式的二维码图片)，不再返回 `secret` 明文。
5. 用户使用谷歌验证器 App 扫描二维码，并在前端页面输入验证器上的 6 位验证码。
6. 前端调用绑定接口 `POST /api/admin/bindGoogle`，传入 `userName` 以及 `code`。
7. 后端从 Redis 中读取 `secret`，校验该 `code` 是否匹配。
8. 如果匹配失败，直接丢弃 Redis 中的缓存；如果匹配成功，将 `secret` 存入数据库完成正式绑定，并清除缓存。下次登录起，便强制要求输入谷歌验证码。

### 3.3 重置 (解绑) 流程
如果用户手机遗失或误删了验证器，导致无法登录：
1. 需要由上级（超级管理员或直属主管）登录系统。
2. 调用重置接口 `POST /api/admin/users/:id/reset-google-auth`，传入需要重置的管理员 ID。
3. 后端验证操作者权限（管理员可重置所有用户，主管仅可重置下属业务员）。
4. 将目标用户的 `google_code` 字段更新为 `null` (即绑定值重置为 false)。
5. 目标用户即可无需验证码直接登录，并可以重新执行“自行绑定流程”。

### 3.4 敏感操作的高级校验
为了系统资金安全，即使已经登录，对于一些核心敏感操作，系统仍要求在请求体中额外传入 `googleCode`。后端会拦截并使用当前管理员的密钥进行实时比对，只有验证通过才允许执行操作。
涉及接口包括但不限于：
- 充值请求审核 (通过/拒绝)
- 提现请求审核 (通过/拒绝)
- 手动增减会员余额
- 提现参数配置修改

## 4. 相关核心 API 列表

| 接口用途 | 请求方法 | 接口路径 | 鉴权要求 | 核心参数 |
| --- | --- | --- | --- | --- |
| 管理员登录 | `POST` | `/api/admin/login` | 公开 | `username`, `password`, `googleCode`(若已绑定则必填) |
| 获取谷歌二维码 | `POST` | `/api/admin/generate-google-auth` | 公开 | `username` (账号), `password` (密码) |
| 绑定谷歌验证码 | `POST` | `/api/admin/bindGoogle` | 公开 | `userName` (账号), `code` (6位验证码) |
| 自行解绑验证码 | `POST` | `/api/admin/unbindGoogle` | 需登录 Token | `username` (账号), `password` (密码) |
| 重置谷歌验证码(解绑) | `POST` | `/api/admin/users/:id/reset-google-auth` | 需登录 Token 及上级权限 | 路径参数 `id` |
