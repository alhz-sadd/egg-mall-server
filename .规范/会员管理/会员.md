# 会员管理接口文档

会员管理模块负责对手机端注册用户进行全生命周期的维护，包括信息查询、状态控制、资金调整及安全重置。系统支持多维度筛选及针对业务员和主管的权限隔离。

## 关联数据库表

- **users**: 核心表，存储手机端用户的基本资料、资产（余额、佣金）、等级及绑定关系。
- **recharge_records**: 记录管理端的手动加减钱流水及第三方充值记录。
- **withdraw_records**: 存储用户的提现申请及打款状态。
- **admin_operation_logs**: 记录管理员对会员执行的修改、充值等敏感操作日志。
- **user_login_logs**: 记录用户的登录活跃数据。

---

## 1. 会员列表与统计

### 获取会员列表
**接口地址**：`GET /api/admin/members`
**接口描述**：支持分页查询及多条件筛选（UID、账号、手机号、业务员、充值状态、真假人等）。

| 参数名 | 类型 | 描述 |
| :--- | :--- | :--- |
| id | Integer | 用户 UID |
| username | String | 账号（模糊查询） |
| has_recharged | Integer | 是否充值：0已充值 1未充值 |
| is_real | Integer | 真人/假人：0真人 1假人 |
| sort_by_asset | String | 资产排序：balance_asc/balance_desc |

### 获取会员统计
**接口地址**：`GET /api/admin/members/statistics`
**接口描述**：返回总注册量、今日/昨日新增、充提人数及次数等汇总数据。

---

## 2. 会员信息修改

### 修改会员备注
**接口地址**：`PUT /api/admin/members/:id/remark`
**请求参数**：`{ "remark": "新备注" }`

### 修改会员状态
**接口地址**：`PUT /api/admin/members/:id/status`
**请求参数**：
- `user_status`: 0正常，1禁用
- `is_real`: true真实，false虚拟
- `withdrawal_status`: true允许提现，false禁止
- `temp_withdraw_status`: 临时提现开关

### 修改 VIP 等级
**接口地址**：`PUT /api/admin/members/:id/vip-level`
**请求参数**：`{ "vip_level": 1-4 }`

---

## 3. 资金与提现管理

### 添加会员金额 (加钱)
**接口地址**：`POST /api/admin/members/add-balance`
**安全要求**：需提供 `googleCode` 二级验证。
**参数说明**：
- `type`: 0赠送，1员工添加，2通道充值

### 扣除会员金额 (扣钱)
**接口地址**：`POST /api/admin/members/deduct-balance`
**安全要求**：需提供 `googleCode` 二级验证，系统会校验余额是否充足。

### 修改提现地址
**接口地址**：`POST /api/admin/ModifyUserWithdrawalAddress`
**参数说明**：`user_id`, `withdraw_id`, `withdraw_address`。

### 获取资金明细
**接口地址**：`GET /api/admin/members/:id/fund-details`
**参数说明**：`type` (0团队收益, 1佣金, 3充值, 4提现)。

---

## 4. 安全与日志

### 重置登录/提现密码
- **重置登录密码**：`POST /api/admin/members/:id/reset-password`
- **重置提现密码**：`POST /api/admin/members/:id/reset-withdraw-password`

### 获取活跃日志
**接口地址**：`GET /api/admin/members/:id/active-logs`
**描述**：查询用户的注册及历史登录记录，包含 IP 和地理位置信息。
